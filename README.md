## About

我关注多模态指代分割、红外图像理解与 AI 系统工程化实现。近期工作围绕热红外场景中的语言驱动目标理解、数据集与 benchmark 构建、深度学习实验复现，以及面向实际场景的前后端系统开发展开。

我希望把科研问题和可运行系统连接起来：一方面理解数据、模型和评测协议，另一方面将算法能力落到可交互、可复现、可展示的工程系统中。

## Projects

### IR-GRES

面向热红外图像的广义指代分割数据集与评测基准。项目基于原 FLIR COCO 格式检测框标注和 SAM2 生成的对应实例掩码，构建 GRES 风格的语言驱动分割样本，并在 DeRIS 框架基础上扩展训练、推理与评估流程。

Repository: [FLMR-HYC/IR_GRES](https://github.com/FLMR-HYC/IR_GRES)

### interview_agent

多模态智能模拟面试系统，将简历解析、问题流编排、语音交互、文本评分、表情分析和反馈报告整合为一个可运行的训练闭环。

Repository: [FLMR-HYC/interview-agent](https://github.com/FLMR-HYC/interview-agent)

### change-detection-system

无人机遥感变化检测 Web 系统，覆盖双时相影像上传、远程推理调度、批量任务、结果可视化、报告生成和巡检记录管理。

Repository: [FLMR-HYC/change-detection-system](https://github.com/FLMR-HYC/change-detection-system)

### hdc_code 数字大屏

数据可视化数字大屏项目，用于展示指标组织、组件化可视化、页面布局和展示型系统开发能力。

Repository: [FLMR-HYC/hdc_code](https://github.com/FLMR-HYC/hdc_code)
